## خطوات التشغيل محلياً
```
npm install
cp .env.example .env.local
# ضيف مفتاح ANTHROPIC_API_KEY بملف .env.local
npm run dev
```
افتح http://localhost:3000

## النشر على Vercel (نفس أسلوب school-tracker)
1. ارفع المجلد كامل لمستودع GitHub جديد (أو استخدم أسلوب paste-and-commit اللي اعتدت عليه)
2. بـ Vercel: New Project → اختر المستودع
3. Framework Preset: **Next.js** (خلاف مشروع school-tracker، هون Next.js فعلي مو "Other")
4. بـ Environment Variables: ضيف `ANTHROPIC_API_KEY`
5. Deploy

## الخطوة الجاية المقترحة (بالترتيب)
1. زر رفع صورة بالواجهة (API جاهز أصلاً لاستقبالها)
2. ربط قاعدة بيانات (Supabase مجاني للبداية) لحفظ:
   - المستخدمين
   - سجل الوجبات اليومي
   - التصحيحات (لتفعيل RAG فعلياً بدل الـ placeholder)
3. تسجيل الدخول (NextAuth: Google + Apple + Email)
4. صفحة الملف الشخصي + حاسبة BMR/BMI
5. صفحة "اليوميات" (Diary) بنمط MyFitnessPal — فطور/غدا/عشا/سناكس
